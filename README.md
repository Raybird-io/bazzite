

# Bazzite + Niri + Dux Labs 

This is a personal repository for a custom [Bazzite](https://bazzite.gg/) boot image. The purpose is to layer and maintain a [Niri](https://github.com/niri-wm/niri) + [Dux labs](https://duxlabs.dev/) focused desktop environment while keeping the benefits of Bazzite. 

# Template used:
Template used to build this image [here](https://github.com/ublue-os/image-template) by Universal Blue
